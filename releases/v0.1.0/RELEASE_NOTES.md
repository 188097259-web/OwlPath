## 数据与公开边界

候选仓库未纳入：

- 运行数据库、主密钥、真实 API 凭据、raw 模型响应或隐藏推理；
- MIMIC、DR.ECC、本地医院或其他患者级数据；
- DeepRare 仓库副本、Git 历史、代码、提示词、数据、模型、视觉资产或归档；
- 原 16 例本地夹具；这些材料未纳入当前拟公开候选。

公开 Agent 回归夹具仅包含 2 例纯合成场景。它们用于检查软件流程和输出合同，不是真实病例、训练数据、临床测试或性能证明。

## Benchmark 表述边界

Benchmark 仅是 50 个独立病例的内部初步比较汇总，不是临床验证。候选中没有逐例配对记录，因此不能独立重算置信区间、配对显著性或效应量。该结果不支持“已经临床有效”、“可用于诊断”或“普遍优于医生/模型”的结论。

3. 当前单一根提交和 `git archive HEAD` 已完成静态边界复核；未来提交与最终上传归档仍需重新扫描。

5. 公开署名为 OwlPath Project Team；项目创始人与临床负责人是 DR.ECC 创始人，真实身份已向比赛组委会披露，但公开仓库不展示姓名、机构或私人邮箱。
