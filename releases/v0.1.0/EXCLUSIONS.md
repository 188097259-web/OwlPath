## 3. 不得通过“排除”暗示的结论

- 排除真实病例不等于已完成临床验证或数据合规审批。
- 排除真实 Provider 轨迹不等于真实 Provider 兼容性已通过。
- 排除 DeepRare 材料不等于第三方依赖许可证审查已完成。
- 排除本地缓存不等于已从干净环境成功复现。

## 4. 每次发布前必须重复执行

1. 冻结拟发布白名单，生成 `SOURCE_INVENTORY.csv` 和 `MANIFEST.sha256`。
2. 对最终归档再次检查文件清单、密钥、数据库头、个人信息和机器路径。
3. 由独立审阅人确认公开边界，再由项目负责人决定是否进入上传准备。
