## 4. 审计限制与未完成门槛

- 模式扫描只能发现已定义的文件类型、密钥样式、SQLite 文件头和机器绝对路径，不能证明不存在所有可能的隐私风险。
- 当前 Git 只有一个本地根提交；已对其可达文件树做同一静态边界检查，并清理了初始化阶段不可达的旧 manifest/inventory blob。尚未生成的发布归档、未来提交或上传后页面不在本次范围内。
- 发布前仍需另一名审阅者人工检查公开夹具、图片元数据、最终文件清单和归档内容。
- 任何将来的 MIMIC、DR.ECC 或本地临床数据运行都必须在另行获批的本地环境中执行，不能因去标识化而默认获得再分发权。
