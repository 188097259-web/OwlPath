# 病原体因果标签仲裁规范 v1

## 1. 为什么“检出”不等于“致病”

病原体预测的真实目标不是“哪项实验室检查阳性”，而是：

> 哪个或哪些病原体最可能解释本次临床综合征？

两者不等价，原因包括：

- 上呼吸道、痰或非无菌部位可出现定植或携带；
- 标本采集或处理过程可产生污染；
- PCR 可检出无症状携带或已失去当前致病意义的残留核酸；
- 抗微生物药使用后，培养可出现假阴性；
- 未做检查或标本不合格不等于病原体不存在；
- 同一患者可能存在共感染。

因此，数据集必须同时保存“检测到什么”和“仲裁后认为什么致病”。

## 2. 三层标签结构

### 2.1 病例层：本次是否为感染

| 标签 | 含义 |
|---|---|
| `infection_confirmed_or_probable` | 综合证据支持本次为感染性下呼吸道疾病 |
| `infection_possible` | 感染可能，但非感染解释仍具明显竞争力 |
| `non_infectious_more_likely` | 心衰、肺栓塞、肺泡出血、药物性肺损伤等更能解释当前综合征 |
| `indeterminate` | 证据不足或相互冲突，无法仲裁 |

### 2.2 病原体层：每个检出或候选病原体的因果地位

| 标签 | 定义 | 可否作为主训练阳性标签 |
|---|---|---|
| `confirmed_causal` | 高质量标本的特异性检测，与综合征、时间轴和宿主状态高度一致，无更好解释 | 是 |
| `probable_causal` | 多项证据一致，但未达到确证强度 | 是，需保留权重或标签不确定性 |
| `possible_causal` | 有一定支持，但仍有其他病原体或非感染解释 | 不建议作为硬阳性；可用于弱监督/敏感性分析 |
| `colonization_or_carriage` | 检出但更符合定植或携带，不足以解释本次疾病 | 否 |
| `contaminant` | 采样、运输、处理或检测过程的污染更可能 | 否 |
| `detected_not_causal` | 检出是真实的，但时间或临床综合征不支持它是本次主要病因 | 否 |
| `not_detected_with_adequate_test` | 合格标本和合适时机下的特异检测阴性 | 只能作为有限的阴性证据 |
| `unknown_inadequate_testing` | 未检测、检查不完整、标本不合格、采样过晚或药物暴露使阴性无法解释 | 不可标为阴性 |

### 2.3 检测层：原始观察

每一项检测必须保留：

- 标本部位与类型；
- 采集时间、结果时间和医生可见时间；
- 采样前抗微生物药暴露；
- 标本质量和是否符合实验室接受标准；
- 检测方法、平台和版本；
- 定性、定量或半定量结果；
- 实验室的污染/定植评估；
- 是否存在重复或相互冲突的检测。

## 3. 证据强度维度

仲裁不应只看某一项阳性，至少审查八个维度：

1. **综合征一致性**：该病原体能否解释当前病程；
2. **标本适当性**：来自感染部位还是易定植部位；
3. **采样质量**：标本是否合格；
4. **时间关系**：检出时间与病程是否一致；
5. **检测性能**：方法的特异度、灵敏度和交叉反应；
6. **定量信息**：菌量、核酸水平或动态变化是否支持致病；
7. **宿主与暴露**：宿主状态、免疫背景、流行病学暴露；
8. **竞争性解释**：是否存在更好的其他病原或非感染诊断。

治疗反应可作为仲裁的辅助背景，但不得单独用作致病标准，也绝不得返回任何早于该信息可见时间的决策快照。

## 4. 仲裁工作流

1. **标签包准备**：数据管理员准备脱敏病程、影像、实验室、标本质量和用药时间轴。
2. **隔离决策快照与标签**：研究用的“最终标签包”可以使用当次决策时点 `t` 之后的信息，但必须与“截至该次 `t` 的模型输入快照”物理或逻辑分离。
3. **双人独立仲裁**：至少一名感染/呼吸临床医师和一名临床微生物专业人员，在不知模型输出的情况下独立标签。
4. **冲突复核**：如病例层标签不同，或主要病原体等级相差超过一级，由第三名高年资专家复核。
5. **共识会议**：仍无法达成共识时，保留 `indeterminate` 或 `possible_causal`，不得强行制造确定标签。
6. **版本化签发**：记录标签规则版本、仲裁者角色、时间、争议理由和最终状态。

## 5. 共感染

- 允许一个病例有多个 `confirmed_causal` 或 `probable_causal` 标签。
- 每个病原体单独评估，不因为已找到一个病原体就自动否定其他病原体。
- 必须记录两者是同时存在、先后感染，还是其中一个只是定植。
- 共感染标签的一致性必须单独报告。

## 6. 不可证实病例的处理

不得把以下情况自动当作“无感染”或“所有病原体阴性”：

- 没有留取标本；
- 只做了少量病原体面板；
- 标本在抗微生物药使用后采集；
- 检测时间与病程不合适；
- 标本被拒收或质量不合格；
- 患者转院或失访，结局不完整。

这些病例应保留为 `unknown_inadequate_testing`，并纳入“未知和弃答”能力的评价，而不是从数据集中全部删除。

## 7. 质量控制

每批数据至少报告：

- 双人仲裁的原始一致率；
- 病例层和病原体层的一致性指标；
- 需第三人复核的比例；
- `indeterminate` 和 `unknown_inadequate_testing` 的比例；
- 定植、污染和检出但非致病的比例；
- 采样前抗微生物药暴露的缺失率；
- 不同医院、人群和检测平台的标签差异。

如仲裁规则改变，必须生成新标签版本，不得覆盖旧标签。
